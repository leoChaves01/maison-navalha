# Maison Navalha

Site responsivo de uma barbearia premium, desenvolvido com Next.js, React e TypeScript.

## Funcionalidades

- Página inicial sofisticada e responsiva
- Apresentação de serviços e profissionais
- Página de agendamento
- Escolha de serviço, barbeiro, data e horário
- Formulário de contato e confirmação

## Executar o projeto

```bash
npm install
npm run dev
```

Depois, acesse http://localhost:3000.

## Produção

```bash
npm run build
npm start
```
